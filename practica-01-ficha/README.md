# practica-01-ficha

## Qué hice

Construí una ficha de personaje en HTML sobre Daenerys Targaryen,
personaje de Game of Thrones y conocida como la Madre de Dragones.

La ficha contiene una imagen del personaje, estadísticas, habilidades,
su historia y un formulario de contacto.

## Cómo correrlo

Abrir el archivo `index.html` en un navegador web.

## URL desplegada

Todavía no está desplegada.

## Qué aprendí

Aprendí a crear una página básica utilizando HTML y a utilizar
diferentes etiquetas como títulos, párrafos, imágenes, tablas,
listas, secciones y formularios.

También aprendí la importancia de utilizar textos alternativos
en las imágenes y etiquetas relacionadas con los campos del formulario.

## Qué no alcancé a hacer

No alcancé a desplegar la página en una plataforma web.

La ficha funciona de manera local abriendo el archivo `index.html`.
